## Project Overview

- **Type:** Claude Code plugin marketplace (monorepo, 5 plugins).
- **Repository:** [aldorea/life-os](https://github.com/aldorea/life-os) · MIT licensed.
- **Primary language:** Markdown (Claude Code skills) + Bash + small Python helpers.
- **Data store:** External Obsidian vault (markdown-first, iCloud-synced). **No database.**
- **Runtime:** Claude Code CLI. Skills are invoked via `/<plugin>:<skill>` slash commands.

## Getting Started

1. Install Claude Code CLI.
2. Add marketplace: `/plugin marketplace add github:aldorea/life-os`.
3. Install plugins you need (start with `rituals` + `sync` + `wiki`).
4. Create `~/.config/life-os/config.yaml` from `config.example.yaml`.
5. Create `~/.config/life-os/secrets.yaml` (600 perms) for API keys.
6. Configure MCP servers (Jira, Slack, Granola, etc.) in `~/.claude.json` or per-project.
7. Run `/rituals:morning` to validate the install.
