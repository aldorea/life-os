**Frontmatter:**
```yaml
- - -
name: dump
description: Use when quickly capturing a thought, task, idea, or anything to the inbox without classification. Use when user says "dump", "anota", "apunta", "inbox", "quick capture", "captura rapida", or provides raw text to save.
- - -
```

**Step 0 -- Load configuration:** Standard pattern. Set VAULT.

**Overview:** Ultra-fast capture to inbox. No classification, no tags, no questions. Just append raw text with timestamp to Inbox.md. Under 5 seconds.

**Process:**

### 1. Capture input
Take the user's text exactly as provided. Do NOT reformulate, classify, or ask questions. Speed is the priority.

### 2. Append to Inbox
Append to `VAULT/{config.structure.inbox}`:
```markdown
- [ ] {user's raw text} <!-- {YYYY-MM-DD HH:MM} -->
```

If Inbox file doesn't exist, create it with header:
```markdown
# Inbox

- [ ] {user's raw text} <!-- {YYYY-MM-DD HH:MM} -->
```

Append at the end of existing content, after the last line.

### 3. Confirm
Show: "Capturado en Inbox. Usa /process-inbox cuando quieras procesar."

No git commit for /dump -- speed over safety. The item is just raw text in inbox, no data at risk.

**Graceful Degradation:**
| Missing | Behavior |
|---------|----------|
| Inbox file doesn't exist | Create it with header |
| Empty input | Ask user what to capture |

**Important Rules:**
- NEVER ask for classification, tags, or context -- that's /process-inbox's job
- NEVER reformulate the input -- capture raw
- Minimize output -- one confirmation line only
- Spanish language for confirmation text
- Do NOT run git commit -- speed is priority, inbox items are ephemeral
