   ```
   Read goals from `VAULT/{config.structure.goals}` (YAML format).

   1. Score each goal: weight * (1 - current/target) * deadline_urgency
   ```

**Frontmatter:**

```yaml
- - -
name: close
description: Use when ending the day, doing end-of-day reflection, or closing out the workday. Use when user says "close", "cierre", "end of day", "fin del dia", "cierra el dia", "reflection", "reflexion".
- - -
```

**Step 0 -- Load configuration:** Standard pattern. Set VAULT.

**Overview:** End-of-day ritual that guides the user through reflection, energy check, and task completion logging. Updates the daily note's "Cierre del dia" section.

**Process:**

### 1. Read today's daily note
Find today's daily note at `VAULT/{config.structure.daily_notes}/{date}.md` (using `{config.daily.date_format}`).
If it doesn't exist: "No hay daily note para hoy. Quieres generarla primero? (/today)"

### 2. Read completed tasks
Read `VAULT/{config.structure.backlog}`. Find tasks marked as done today `- [x]` (Obsidian Tasks marks done date).
Also check today's daily note "Completadas hoy" section.

### 3. Review the day
Present a summary of the day:
```
## Cierre del dia — {date}

Foco del dia: [from daily note]
Reuniones: X (from daily note agenda)

Tareas completadas hoy: Y
- [x] Tarea uno
- [x] Tarea dos

Tareas pendientes #next no completadas: Z
- [ ] Tarea pendiente uno
- [ ] Tarea pendiente dos
```

### 4. Interactive reflection
Ask the user these questions one at a time:

**"Que salio bien hoy?"**
Wait for user response. Capture their text.

**"Que harias diferente?"**
Wait for user response. Capture their text.

**"Energia del dia?"**
Show options: "1) Baja (roja) 2) Media (amarilla) 3) Alta (verde)"
Wait for user selection.

### 5. Handle pending tasks
For each #next task that was not completed today:
```
Tarea: "[task text]"
- Mantener como #next para manana? (s)
- Reprogramar para otra semana? (r)
- Mover a someday? (m)
- Ya no es relevante? (x)
```
Batch these decisions -- present all, then apply after confirmation.

### 6. Git safety (per D-14)
Before any writes:
- `git -C VAULT add {daily_note} {backlog}`
- `git -C VAULT commit -m "backup: before close ritual"`

### 7. Update daily note
Write to the "Cierre del dia" section of today's daily note:
```markdown
## Cierre del dia

**Que salio bien?**
[user's response]

**Que haria diferente?**
[user's response]

**Energia:** [emoji based on selection: baja=rojo, media=amarillo, alta=verde]
```

Do NOT overwrite any other section of the daily note.

### 8. Apply task changes
Based on Step 5 decisions:
- Tasks kept as #next: no change needed
- Tasks reprogrammed: update week tag to target week
- Tasks moved to someday: add #someday tag, move to "Algun dia" section
- Tasks marked irrelevant: mark as `- [x]` with note "Descartada"

### 9. Git commit result
- `git -C VAULT add {daily_note} {backlog}`
- `git -C VAULT commit -m "ritual(close): end-of-day reflection {date}"`

### 10. Good night summary
```
Dia cerrado.
Completadas: X tareas
Energia: [emoji]
Pendientes: Y tareas para manana
[if any moved to someday: "Z tareas movidas a Algun dia"]

Descansa bien!
```

**Graceful Degradation:**
| Missing | Behavior |
|---------|----------|
| No daily note | Offer to create one, or skip to reflection only |
| No completed tasks | Skip "what went well" section, still ask reflection |
| No pending #next tasks | Skip Step 5 task review |
| Backlog doesn't exist | Skip task management, reflection only |

**Important Rules:**
- NEVER overwrite existing content in daily note sections other than "Cierre del dia"
- ALWAYS wait for user input at each reflection question
- ALWAYS confirm before modifying Backlog tasks (per D-15)
- Apply git safety before any writes (per D-14)
- Spanish language for all output
- Energy emoji: baja = rojo, media = amarillo, alta = verde (matching existing daily note template)
